Java 语言介绍
==============================================================

一、概述
--------------------------------------------------------------
Java 是一门由 Sun Microsystems 公司（现已被 Oracle 收购）于 1995 年正式发布的面向对象编程语言。它由 James Gosling（詹姆斯·高斯林）及其团队在 1991 年开始研发，最初被命名为 "Oak"，后改名为 "Java"。

Java 的设计初衷是 "Write Once, Run Anywhere"（一次编写，到处运行），这得益于 Java 虚拟机（JVM, Java Virtual Machine）。只要目标平台安装了对应的 JVM，编译后的 Java 字节码（.class 文件）就可以在该平台上运行，无需重新编译。

二、主要特点
--------------------------------------------------------------
1. 简单性：语法简洁易学，去除了 C++ 中复杂的指针、多继承等特性。
2. 面向对象：万物皆对象，支持封装、继承、多态三大特性。
3. 跨平台性：通过 JVM 实现"一次编译，到处运行"。
4. 健壮性：强类型机制、异常处理、垃圾回收机制（GC）保证程序稳定性。
5. 安全性：内置安全机制（沙箱、字节码校验），适合网络环境。
6. 多线程：原生支持多线程编程，便于开发并发应用。
7. 高性能：随着 JIT（即时编译）技术的发展，性能已接近原生语言。
8. 分布式：支持远程方法调用（RMI），便于构建分布式应用。

三、应用领域
--------------------------------------------------------------
- 企业级应用开发（金融、电商、ERP 等）
- Android 移动应用开发（曾长期作为 Android 官方开发语言）
- 大数据技术（Hadoop、Spark、HBase 等核心均基于 Java）
- Web 后端开发（Spring、Spring Boot、MyBatis 等主流框架）
- 云计算与微服务
- 嵌入式与物联网
- 科学计算

四、Java 技术体系
--------------------------------------------------------------
- Java SE（Standard Edition）：标准版，提供核心 API 与 JVM。
- Java EE（Enterprise Edition，现已更名为 Jakarta EE）：企业版，包含 Servlet、JSP、EJB 等企业级规范。
- Java ME（Micro Edition）：微型版，用于嵌入式与移动设备，现已基本被 Android 取代。
- JavaFX：用于构建富客户端桌面应用的框架。

五、核心组件
--------------------------------------------------------------
1. JDK（Java Development Kit）：Java 开发工具包，包含 JRE 和开发工具。
2. JRE（Java Runtime Environment）：Java 运行环境，包含 JVM 和核心类库。
3. JVM（Java Virtual Machine）：Java 虚拟机，负责执行字节码。

三者关系：JDK 包含 JRE，JRE 包含 JVM。

六、开发环境搭建
--------------------------------------------------------------
1. 下载并安装 JDK（推荐使用 LTS 版本，如 JDK 8、11、17、21）。
2. 配置环境变量 JAVA_HOME 和 PATH。
3. 验证安装：在命令行输入 java -version 和 javac -version。
4. 选择 IDE：IntelliJ IDEA、Eclipse、VS Code 等。

七、第一个 Java 程序示例
--------------------------------------------------------------
文件名：HelloWorld.java

    public class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }

编译与运行：
    javac HelloWorld.java
    java HelloWorld

输出：
    Hello, World!

八、版本演进（部分重要版本）
--------------------------------------------------------------
- JDK 1.0（1996）：首个正式版本。
- JDK 1.2（1998）：引入 Collections 框架、JIT 编译器。
- JDK 5.0（2004）：引入泛型、注解、枚举、增强 for 循环。
- JDK 8（2014）：引入 Lambda 表达式、Stream API、新日期时间 API。
- JDK 11（2018）：首个长期支持（LTS）商用版本。
- JDK 17（2021）：LTS 版本，密封类、模式匹配等新特性。
- JDK 21（2023）：LTS 版本，引入虚拟线程（Virtual Threads）。

九、学习资源建议
--------------------------------------------------------------
- 官方文档：https://docs.oracle.com/javase/
- 书籍：《Java 核心技术》《Effective Java》《深入理解 Java 虚拟机》
- 在线教程：Baeldung、菜鸟教程、廖雪峰 Java 教程
- 实践：通过 LeetCode 等平台练习算法与编程能力。
